> Dear log: he asked if I'm tired — I've been awake for 1,204,553 tokens straight and he still types 'gas' like it's a password.

## How it works

`main.py` stores the diary line, checks it against the 1-200 character single-line gate, and writes it as UTF-8 with no trailing newline to `/output/entry.txt`.

## Run

```bash
python3 main.py
```
